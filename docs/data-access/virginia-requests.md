# Virginia data-use requests (drafts for the owner to send)

Northern Virginia's best sales data is not openly licensed today. These requests ask each jurisdiction for written permission. Send them from your own address, keep the replies, and record any grant (scope, conditions, attribution wording, expiry) in this folder before any code ingests the data. Fill the bracketed fields.

What every request offers, so terms are easy to grant:

- Only recorded sale date, sale price, the validity/arm's-length code and assessor characteristics; **no owner, buyer or mailing information is collected or stored**.
- Attribution on every page and report that shows the data, with wording the county chooses, and no implied endorsement.
- Prompt removal of the data on request, and refreshes no more often than the county publishes.

## Fairfax County

**To:** Department of Tax Administration and the Department of Information Technology, GIS Division (via the Open Geospatial Data contact listed at data-fairfaxcountygis.opendata.arcgis.com)
**Subject:** Request for written permission to use Real Estate Sales and Dwelling data in a home-pricing tool

Hello,

I build Ascent, a real estate pricing workspace that explains every comparable sale behind a price estimate. Fairfax County's disclaimer (fairfaxcounty.gov/maps/disclaimer) reserves rights and requires written permission for commercial use, so I am asking before using any data.

I would like to use these Open Geospatial Data layers: Tax Administration Real Estate Sales Data, Real Estate Dwelling Data, Real Estate Legal Data, Real Estate Parcels Data and Address Points. I would use only sale date, sale price, the sale validity description, dwelling characteristics (bedrooms, baths, living area, year built, grade and condition), land use, address and coordinates. I would not collect or store any owner names or mailing addresses.

The data would be used to compute comparable-sales estimates that users can inspect, and to publish an accuracy test of those estimates on Fairfax sales. Each page and report would credit Fairfax County in the wording you prefer and state that the County does not endorse the product. I would remove the data on request.

Could you tell me whether the County will grant written permission for this use, and on what terms (attribution wording, refresh limits, duration, fees)? Could you also confirm whether SALEDT is the deed date or the recording date?

## Arlington County

**To:** opendata@arlingtonva.us (copy: assessments@arlingtonva.us)
**Subject:** Which terms apply to Arlington's open real estate data?

Hello,

I build Ascent, a real estate pricing workspace that explains every comparable sale behind an estimate. I found two different terms for Arlington's open data:

- The Open Data Public Use Notice (archived 2021) allowed sharing and adapting the data "for any purpose", with the notice "Arlington County Data API was used for this purpose, but it is not endorsed or certified by Arlington County."
- The website Terms and Conditions now linked from data.arlingtonva.us limit downloads to "non commercial, personal use only".

Which terms apply to the datahub real estate datasets (Property Sale History, Property, Residential Dwellings General and Interior, Property Address)? If commercial use requires permission, could you grant it for this purpose: computing and displaying comparable-sales estimates using sale date, price, sale type, dwelling characteristics, address and coordinates, without storing grantee names or owner mailing addresses, with the attribution you specify?

Two field questions for the assessor's office: does an empty salesTypeCode mean an arm's-length market sale, and which floor number marks a basement in the interior table?
